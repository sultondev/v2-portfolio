UX notes — Home

  • Sticky nav — top of page, condenses on scroll.
  • Hero is asymmetric: H1 anchored left, visual offset bottom-right (cyberpunk hint).
  • Primary CTA: View Work. Secondary: Get in Touch.
  • Scroll flow: Hero → About → Stack → Projects → CTA → Footer.
  • Hierarchy: H1 dominant; About + Projects equal weight; Stack supportive.
